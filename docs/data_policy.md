# Data and release scope

The public package contains selected source code, aggregate metrics, and presentation material. It excludes original narratives, case identifiers, row-level predictions, checkpoints, credentials, private infrastructure configuration, author agreements, correspondence and the original research Git history.

Obtain the WomenHelp data from the organizers under their applicable terms. This repository grants no rights to redistribute that corpus. The demo uses explicitly artificial placeholder records and is a software check, not benchmark evidence.

The source was checked against the June 22 camera-ready project snapshot. Portability changes replace private absolute paths with relative defaults and retain standard TLS certificate verification. The public package is a curated implementation snapshot; it is not a promise that every historical experiment can be exactly rerun without the original environment, data and trained weights.

The author name, institutional affiliation and requested GitHub account remain as intentional scholarly attribution. Personal contact addresses are omitted. Automated privacy checks complement manual selection; they are not a guarantee that every possible sensitive pattern can be detected.
